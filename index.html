iMara Blast

Desktop tool to publish images and videos across social platforms simultaneously.

Supported platforms

Facebook

Publishes photos and videos directly to a Facebook Page via the Graph API.

Operational

Instagram

Publishes images and Reels to an Instagram Business account via resumable upload.

Operational

TikTok

Uploads and publishes short videos via the TikTok Content Posting API.

Pending review

Twitter / X

Posts images and videos via the X API v2 using OAuth 1.0a.
